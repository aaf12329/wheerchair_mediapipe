# Python 依赖 / Python dependencies

支持 Python 3.10 及以上。Windows 上可在现有 `mul_pro` 环境中运行，`pytest` 用于离线测试。

Requires Python 3.10 or later. On Windows, you can use the existing `mul_pro` environment. `pytest` is used for offline tests.

```powershell
python -m pip install opencv-contrib-python mediapipe numpy pillow pyserial pytest
```
